1. EXECUTIVE OVERVIEW & APPLICATION PURPOSE
--------------------------------------------------------------------------------
Observed Target: [Remove AI Label](https://tahmidx.tech/ai-remove/) is a 100% client-side, single-page web utility designed to strip embedded AI provenance and camera/editing metadata from digital images directly inside the user's browser.
Observed Purpose: By drawing uploaded images onto an in-memory HTML5 Canvas and re-encoding the raw pixel buffer via canvas.toDataURL(file.type, 1.0), the application strips C2PA manifests, XMP packets, EXIF tags, and PNG text/ancillary chunks so automated social media metadata parsers (such as Instagram and Facebook AI labels) no longer flag the image via metadata inspection.
Observed Architecture: Pure static frontend (Vanilla HTML5, CSS3 with Material Design 3 custom properties, and ES6+ JavaScript) with zero backend API endpoints for image processing. Multi-file batch downloads are packaged client-side using [JSZip 3.10.1](https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js) loaded from the Cloudflare CDN.

5. JAVASCRIPT STATE MACHINE & CORE LOGIC SPECIFICATION
--------------------------------------------------------------------------------
Below is the complete behavioral specification observed on [Remove AI Label](https://tahmidx.tech/ai-remove/) for the JavaScript implementation:

  A. State Variables:
     - currentZip = null: Holds the active [JSZip 3.10.1](https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js) instance when processing multiple images.
     - singleImageData = null: Holds { dataUrl, name } when processing a single image.

  B. Event Listeners:
     1. dropZone 'click' -> Invokes fileInput.click().
     2. dropZone 'dragover' -> Calls e.preventDefault() and adds class 'dragover' to dropZone.
     3. dropZone 'dragleave' -> Removes class 'dragover' from dropZone.
     4. dropZone 'drop' -> Calls e.preventDefault(), removes class 'dragover', and passes e.dataTransfer.files to processFiles(files).
     5. fileInput 'change' -> Passes e.target.files to processFiles(files).
     6. downloadBtn 'click' -> Triggers either single-file download or multi-file ZIP download.

  C. Function: async processFiles(files)
     1. Filter input FileList into an array of valid images where file.type.startsWith('image/').
     2. Validation: If the filtered array is empty, call alert('Please upload valid image files') and return immediately.
     3. UI Transition to Processing State:
        - Save original dropzone title text ("Click or drag images here").
        - Update .drop-zone-title text to "Processing..." (or progress indicator).
        - Hide #preview-container (style.display = 'none').
        - Reset currentZip = null and singleImageData = null.
     4. Single vs. Batch Branching:
        - If validFiles.length === 1:
            * Call const dataUrl = await processSingleFile(validFiles[0], null).
            * Store singleImageData = { dataUrl: dataUrl, name: 'clean_' + validFiles[0].name }.
            * Set preview.src = dataUrl and preview.style.display = 'block'.
            * Set fileCountText.textContent = '1 image ready (Metadata stripped)'.
            * Set downloadText.textContent = 'Download Clean Image'.
        - If validFiles.length > 1:
            * Instantiate currentZip = new JSZip().
            * Map/iterate over validFiles and await processSingleFile(file, currentZip) for each file.
            * Set preview.src to the first processed image's dataUrl (or display preview) and set fileCountText.textContent = validFiles.length + ' images ready (Metadata stripped)'.
            * Set downloadText.textContent = 'Download All as ZIP (' + validFiles.length + ')'.
     5. UI Transition to Ready State:
        - Show #preview-container (style.display = 'flex').
        - Restore .drop-zone-title text via resetUI(originalText).

  D. Function: processSingleFile(file, zipInstance)
     1. Return a new Promise((resolve, reject) => { ... }).
     2. Instantiate const reader = new FileReader().
     3. On reader.onload = (event) => {
          const img = new Image();
          img.onload = () => {
            const canvas = document.createElement('canvas');
            canvas.width = img.width;
            canvas.height = img.height;
            const ctx = canvas.getContext('2d');
            ctx.drawImage(img, 0, 0);
            const cleanDataUrl = canvas.toDataURL(file.type, 1.0);
            if (zipInstance) {
              const base64Data = cleanDataUrl.split(',')[1];
              zipInstance.file('clean_' + file.name, base64Data, { base64: true });
            }
            resolve(cleanDataUrl);
          };
          img.onerror = reject;
          img.src = event.target.result;
        };
     4. On reader.onerror = reject.
     5. Call reader.readAsDataURL(file).

  E. Download Button Handler (downloadBtn 'click'):
     1. If currentZip is non-null (Multi-file mode):
        - Update downloadText.textContent = 'Generating ZIP...'.
        - Call const content = await currentZip.generateAsync({ type: 'blob' }).
        - Create const url = URL.createObjectURL(content).
        - Create temporary &lt;a&gt; element, set a.href = url, a.download = 'cleaned_images.zip', append to document.body, call a.click(), remove &lt;a&gt;, and call URL.revokeObjectURL(url).
        - Restore downloadText.textContent.
     2. Else if singleImageData is non-null (Single-file mode):
        - Create temporary &lt;a&gt; element, set a.href = singleImageData.dataUrl, a.download = singleImageData.name, append to document.body, call a.click(), and remove &lt;a&gt;.

  F. Function: resetUI(originalText)
     - Restores .drop-zone-title textContent back to originalText ("Click or drag images here") and clears fileInput.value = '' so the same file can be selected again if needed.

    const fileInput = document.getElementById(&#39;file-input&#39;);
    const previewContainer = document.getElementById(&#39;preview-container&#39;);
    const preview = document.getElementById(&#39;preview&#39;);
    const fileCountText = document.getElementById(&#39;file-count-text&#39;);
    const downloadBtn = document.getElementById(&#39;download-btn&#39;);
    const downloadText = document.getElementById(&#39;download-text&#39;);

    let currentZip = null;
    let singleImageData = null;

    dropZone.addEventListener(&#39;click&#39;, () =&gt; fileInput.click());

    dropZone.addEventListener(&#39;dragover&#39;, (e) =&gt; {

      dropZone.classList.add(&#39;dragover&#39;);

    dropZone.addEventListener(&#39;dragleave&#39;, () =&gt; {
      dropZone.classList.remove(&#39;dragover&#39;);
    });

    dropZone.addEventListener(&#39;drop&#39;, (e) =&gt; {
      e.preventDefault();
      dropZone.classList.remove(&#39;dragover&#39;);
      if (e.dataTransfer.files.length) {

      }

    fileInput.addEventListener(&#39;change&#39;, (e) =&gt; {
      if (e.target.files.length) {
        processFiles(e.target.files);
      }
    });

    async function processFiles(files) {
      const validFiles = Array.from(files).filter(file =&gt; file.type.startsWith(&#39;image/&#39;));
      if (validFiles.length === 0) {
        alert(&#39;Please upload valid image files&#39;);
        return;
      }

      const originalText = &#39;Click or drag images here&#39;;
      dropZoneTitle.textContent = &#39;Processing...&#39;;
      previewContainer.style.display = &#39;none&#39;;
      currentZip = null;
      singleImageData = null;

      try {
        if (validFiles.length === 1) {
          const cleanDataUrl = await processSingleFile(validFiles[0], null);
          singleImageData = {
            dataUrl: cleanDataUrl,
            name: &#39;clean_&#39; + validFiles[0].name
          };
          preview.src = cleanDataUrl;
          fileCountText.textContent = &#39;1 image ready (Metadata stripped)&#39;;
          downloadText.textContent = &#39;Download Clean Image&#39;;
        } else {
          currentZip = new JSZip();
          let firstDataUrl = null;
          for (let i = 0; i &lt; validFiles.length; i++) {
            const cleanDataUrl = await processSingleFile(validFiles[i], currentZip);
            if (i === 0) firstDataUrl = cleanDataUrl;
          }
          preview.src = firstDataUrl;
          fileCountText.textContent = `${validFiles.length} images ready (Metadata stripped)`;
          downloadText.textContent = `Download All as ZIP (${validFiles.length})`;
        }

        previewContainer.style.display = &#39;flex&#39;;
      } catch (err) {
        console.error(err);
        alert(&#39;An error occurred while processing the images.&#39;);
      } finally {
        resetUI(originalText);
      }
    }

    function processSingleFile(file, zipInstance) {
      return new Promise((resolve, reject) =&gt; {
        const reader = new FileReader();
        reader.onload = (event) =&gt; {
          const img = new Image();
          img.onload = () =&gt; {
            const canvas = document.createElement(&#39;canvas&#39;);
            canvas.width = img.width;
            canvas.height = img.height;
            const ctx = canvas.getContext(&#39;2d&#39;);
            ctx.drawImage(img, 0, 0);
            const cleanDataUrl = canvas.toDataURL(file.type, 1.0);

            if (zipInstance) {
              const base64Data = cleanDataUrl.split(&#39;,&#39;)[1];
              zipInstance.file(&#39;clean_&#39; + file.name, base64Data, { base64: true });
            }
            resolve(cleanDataUrl);
          };
          img.onerror = reject;
          img.src = event.target.result;
        };
        reader.onerror = reject;
        reader.readAsDataURL(file);
      });
    }

    function resetUI(originalText) {
      dropZoneTitle.textContent = originalText;
      fileInput.value = &#39;&#39;;
    }

    downloadBtn.addEventListener(&#39;click&#39;, async () =&gt; {
      if (currentZip) {
        const prevLabel = downloadText.textContent;
        downloadText.textContent = &#39;Generating ZIP...&#39;;
        const content = await currentZip.generateAsync({ type: &#39;blob&#39; });
        const url = URL.createObjectURL(content);
        const a = document.createElement(&#39;a&#39;);
        a.href = url;
        a.download = &#39;cleaned_images.zip&#39;;
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
        URL.revokeObjectURL(url);
        downloadText.textContent = prevLabel;
      } else if (singleImageData) {
        const a = document.createElement(&#39;a&#39;);
        a.href = singleImageData.dataUrl;
        a.download = singleImageData.name;
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
      }
    });

7. OPTIONAL PRODUCTION ENHANCEMENTS (DESIGN CHOICES VS. OBSERVED BEHAVIOR)
--------------------------------------------------------------------------------
In accordance with the Reverse Engineer Anything (REA) skill guidelines, the following optional improvements are explicitly separated from the observed target behavior on [Remove AI Label](https://tahmidx.tech/ai-remove/):

  - Memory Efficiency for Large Batches (Design Choice):
    * Observed Behavior: Uses canvas.toDataURL(file.type, 1.0), which allocates Base64 strings in memory.
    * Optional Enhancement: Replace canvas.toDataURL with canvas.toBlob((blob) => ..., file.type, 1.0) and pass the binary Blob directly to zipInstance.file('clean_' + file.name, blob) to reduce peak browser memory usage by ~33% on large high-resolution batches.
  - Filename Collision Guard in Batch ZIPs (Design Choice):
    * Observed Behavior: Writes 'clean_' + file.name directly into JSZip, which overwrites entries if two dropped files share the same filename.
    * Optional Enhancement: Append a numeric suffix (e.g., clean_image_1.png) if zipInstance.file('clean_' + file.name) already exists.
